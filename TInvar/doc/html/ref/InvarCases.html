InvarCases

InvarCases[s,d]

returns the list of cases of order (number of metric derivatives) s and degree (number of Riemanns) d.

InvarCases[s]

returns the list of cases of order s.

InvarCases[]

returns the list of all cases handled by Invar (currently the 47 cases up to order 12 plus the algebraic case of degree 7).
