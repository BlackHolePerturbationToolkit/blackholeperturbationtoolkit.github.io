## Overview

EMRISurrogate is a Python package for evaluating EMRISur1dq1e4, a surrogate
gravitational waveform model trained on waveform data generated by point-particle
black hole perturbation theory (ppBHPT). The model covers non-spinning black hole
binaries with mass ratios from 3 to $10^4$.

![EMRI surrogate]({{ '/assets/img/modules/emrisurrogate/BHPTK-EMRI.png' | relative_url }})

## Model details

The "raw" surrogate model is defined by

$$
h_{\tt S}(t, \theta, \phi) = \sum^{\infty}_{\ell=2} \sum_{m=-\ell}^{\ell} h_{\tt S}^{\ell,m}(t) \, {}^{-2}Y_{\ell m}(\theta, \phi) \,,
$$

where ${}^{-2}Y\_{\ell m}$ are the spin-weight $-2$ spherical harmonics. The surrogate
model provides fast evaluations of the modes $h\_{\tt S}^{\ell,m}$. The available modes are

$$
(\ell,m) = (2,2), (2,1), (3,3), (3,2), (3,1), (4,4), (4,3), (4,2), (5,5), (5,4), (5,3) \,,
$$

while the $m<0$ modes follow from $h^{\ell,-m} = (-1)^{\ell} \left(h^{\ell,m}\right)^\*$.

By default, the package returns rescaled waveform modes,

$$
h^{\ell,m}_{\tt S, \alpha}(t ; q) = \alpha \, h^{\ell,m}_{\tt S}\left( t \alpha; q \right) \,,
$$

where the total-mass rescaling parameter $\alpha(q)$ is tuned to NR simulations
(Eq. 4 of [Rifat et al.](https://arxiv.org/abs/1910.10473)). $\alpha$ approaches unity in
the extreme-mass-ratio limit. Most users will want the NR-tuned model. To generate pure
point-particle perturbation theory waveforms without any tuning to NR ($\alpha = 1$),
pass `calibrated=False` to `generate_surrogate`.

## Installation

EMRISurrogate is not packaged for pip. Clone the repository and download the surrogate
data file, which is hosted on [Zenodo](https://zenodo.org/record/3612600):

```bash
git clone https://github.com/BlackHolePerturbationToolkit/EMRISurrogate.git
cd EMRISurrogate
wget https://zenodo.org/record/3612600/files/EMRISur1dq1e4.h5
```

The code looks for `EMRISur1dq1e4.h5` in the current working directory and tries to
download it with `wget` if it is missing. Either move the file into the directory you work
from, or create a symbolic link to it there.

The module `emri_sur_load.py` needs numpy, scipy, h5py, matplotlib and
[gwtools](https://pypi.org/project/gwtools/). Parts of the accompanying notebook also need
[gwsurrogate](https://pypi.org/project/gwsurrogate/) (`pip install gwsurrogate`), but you
don't need it to evaluate the EMRI surrogate model.

## Usage

Run Python from the repository directory (or add it to your path) and import
`emri_sur_load`. Its `generate_surrogate` function returns the time array and a
dictionary of modes keyed by `(l, m)`:

```python
import emri_sur_load as emriSur

# NR-calibrated modes in geometric units (all available modes by default)
t, h = emriSur.generate_surrogate(100.0)
h22 = h[(2, 2)]

# raw (uncalibrated) ppBHPT waveform
t_raw, h_raw = emriSur.generate_surrogate(100.0, calibrated=False)

# physical units: total mass in solar masses, distance in Mpc
t_phys, h_phys = emriSur.generate_surrogate(100.0, M_tot=80.0, dist_mpc=500.0)
```

Pass `modes=[(2,2), (3,3)]` (for example) to return only a subset of the modes. You
must give both `M_tot` and `dist_mpc` to get physical-unit waveforms.
